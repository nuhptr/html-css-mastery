CSS Container Queries ( @container )

Components query their own named ancestor container width ( inline-size ) rather than the browser viewport.

Main container ( container-name: main ): turns warm peach when its own inline size drops below 600px , otherwise renders mint green.

Sidebar container ( container-name: aside ): turns emerald tint when its inline size drops below 300px .
