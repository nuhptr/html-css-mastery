CSS Custom Properties ( :root Variables)

1fr Column ( --box-1-width: 1 )

Design tokens declared on :root centralize colors, spacing, and proportions so theme updates happen in one place.

2fr Column ( --box-2-width: 2 )

This column uses flex: var(--box-2-width) to stay twice as wide as its sibling while sharing the exact same palette variables.
